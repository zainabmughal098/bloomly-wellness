# 🌷 Bloomly — Your Daily Wellness Companion

> **"Small habits. Better days."**

Bloomly is an intentional, compassionate, local-first daily routine and personal wellness companion. Built with a gentle aesthetic and a non-punitive mindset, Bloomly helps you cultivate daily rhythms, track hydration, meals, movement, sleep, habits, and self-care without pressure, guilt, or digital burnout.

## 🌿 Problem Statement

Most modern wellness, habit, and health trackers are built around aggressive streaks, rigid metrics, and cognitive pressure. When a user misses a single day, streak counters reset to zero, inducing guilt and often leading users to abandon their habits altogether. Furthermore, many commercial trackers require account registrations, cloud synchronizations, and subscription paywalls, exposing sensitive health routines to third-party telemetry.

**Bloomly takes a different approach:**
- **Zero Guilt, Zero Pressure**: There are no punitive streak resets. If you miss a task, your companion flower simply waits patiently for your next return.
- **Holistic Care Over Isolated Metrics**: Health isn't just steps or calories—it's hydration, nourishing food, rest, gentle movement, mindful routines, and emotional check-ins working together in harmony.
- **Complete Data Sovereignty**: Your daily routines, sleep notes, mood entries, and personal goals never leave your device.

## ✨ Key Features

### 1. Today's Bloom Gamification System
- **Composite Daily Score (0–100%)**: Dynamically aggregates your day across routines (25%), movement (20%), hydration (15%), nourishment (15%), sleep rest (10%), habits (10%), and mood check-in (5%).
- **Botanical Growth Stages**: Watch your flower transition through living visual states: *Sprout*, *Budding*, *Blooming*, and *Radiant Bloom*.
- **Interactive Companion Flowers**: Choose your companion flower—**Tulip**, **Sunflower**, **Rose**, **Daisy**, or **Lavender**—each carrying an uplifting symbolic meaning.
- **Non-Punitive Philosophy**: Every small action nurtures your bloom. Missed days are never scored with negative reinforcement.

### 2. Routine & Habit Management
- **Time-of-Day Rhythms**: Group routine tasks by Morning, Afternoon, Evening, or Anytime.
- **Customizable Step Targets**: Set personalized times, icon markers, and gentle reminders.
- **Habit Tracker**: Track habits with customizable frequency targets, category tags, streak counters, and weekly completion heatmaps.

### 3. Hydration Tracker
- **Visual Fill Gauge**: Dynamic water progress bar with real-time percentage progress.
- **Quick-Log Buttons**: Instant one-tap logging (+250ml cup, +500ml bottle) or custom amount input.
- **Personalized Target**: Set your daily hydration target (e.g., 2,000 ml) in settings.

### 4. Mindful Meal Logging
- **Daily Rhythm**: Log Breakfast, Lunch, Dinner, and Snacks.
- **Nourishment Check-In**: Celebrate consistent nourishment without restrictive calorie counting.

### 5. Movement & Step Tracking
- **Dual Tracking**: Record daily steps alongside active movement minutes (walking, yoga, stretching, running, cycling).
- **Distance Estimation**: Automatically converts logged steps to estimated kilometers walked.
- **Quick Logging**: Convenient increment shortcuts (+500 steps, +15 mins movement).

### 6. Sleep & Rest Logger
- **Rest Reflection**: Log bedtime, wake time, total duration, and sleep quality (Restful, Fair, Restless).
- **Sleep Target**: Compare nightly sleep duration against your personalized goal (e.g., 8.0 hours).

### 7. Mood & Self-Care Rituals
- **Emotional Sentiment Check-in**: Track how you feel each day (Great, Good, Okay, Low, Exhausted) with optional private reflection notes.
- **Self-Care Grid**: Quick-check mindful self-care rituals, including *Breathing / Meditation*, *Warm Bath or Shower*, *Reading*, *Nature Walk*, *Digital Detox*, and *Gentle Stretching*.
- **Responsive Multi-Line Cards**: Self-care cards feature flexible multi-line wrapping so long activity labels never cut off awkwardly on compact mobile screens.

### 8. Bloom Garden
- **Visual Growth Sanctuary**: A visual record of past blooms where each completed day is planted as a blossoming flower.
- **Gentle Historical Log**: Browse past days and celebrate your journey over weeks and months.

### 9. Weekly Wrapped
- **7-Day Celebration**: An aesthetic summary of your weekly consistency, total hydration, steps walked, routine steps completed, and average sleep.
- **Client-Side Story Card Generator**: Exports a 9:16 Instagram Story-style graphic directly to PNG using the HTML5 Canvas API—completely offline with zero remote rendering services.
- **Share & Clipboard Export**: One-tap text summary copy and native Web Share integration where supported.

### 10. Wellness Insights & Trajectory
- **Dynamic Time Range**: Analyze trends over 7 Days, 30 Days, or 3 Months (90 Days).
- **Custom SVG Trend Chart**: Smooth gradient area chart with an 80% goal reference line and interactive data points.
- **Local Smart Insights**: Algorithmic discoveries generated purely on-device from your local data patterns (e.g., correlations between sleep and routine completion).

### 11. Personalized Onboarding & Motivational Quotes
- **Welcoming 5-Step Setup**: Personalizes your companion name, optional gender identity, focus areas, daily targets, and starter flower.
- **Daily Motivational Quotes**: A rotating collection of calming, stoic, and encouraging quotes to start your day with intention.
- **Daily Tips**: Gentle wellness tips categorized by hydration, mindfulness, movement, and sleep.

### 12. Responsive Mobile Design
- **Dedicated Mobile Navigation**: Persistent, ergonomic bottom navigation with direct access to *Today*, *Routine*, an elevated center *Quick Log* button, *Insights*, and *Profile*.
- **Tested Across Viewports**: Optimized for displays ranging from 320px ultra-compact mobile screens (e.g., iPhone SE) up to ultra-wide desktop monitors.
- **Touch-Friendly Targets**: Minimum 44px touch targets, smooth transitions, and tactile feedback.

## 🔒 Local-First & Privacy-Focused Architecture

Bloomly is designed with strict data privacy principles:

- **100% Client-Side**: All data processing, score calculations, analytics generation, and image exports happen entirely in your browser.
- **No External AI API Keys**: Bloomly operates out-of-the-box without requiring OpenAI, Gemini, or any third-party paid AI API credentials.
- **No Cloud Database Required**: Bloomly does not transmit your personal logs to any external server or telemetry endpoint.
- **Browser LocalStorage**: State is preserved securely across browser sessions via standard `localStorage`.
- **Complete Data Portability**:
  - **Export My Data**: Download your entire profile, preferences, routines, and wellness logs as a clean, human-readable JSON file at any time.
  - **Import Data**: Easily restore your data on any device by uploading your JSON backup.
  - **Restart Onboarding**: Re-run the initial setup wizard anytime without losing your historical logs.
  - **Delete All Data**: Complete, irreversible local data wiping with a single click.

## 🚀 Installation & Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.x, 20.x, or later)
- [npm](https://www.npmjs.com/) (version 9.x or later)

### Step 1: Clone the repository
```bash
git clone https://github.com/your-username/bloomly.git
cd bloomly
```

### Step 2: Install dependencies
```bash
npm install
```

### Step 3: Run the development server
```bash
npm run dev
```

The application will start locally at:
```
http://localhost:3000
```

### Step 4: Validate code formatting and types
```bash
npm run lint
```

### Step 5: Build for production
```bash
npm run build
```
This outputs compiled, optimized static production assets into the `dist/` folder.
